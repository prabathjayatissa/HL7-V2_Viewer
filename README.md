# HL7-V2_Viewer
The project is already set up and running — dependencies are installed and the dev server runs automatically. Here are the steps if you want to run it from scratch:

1. Install dependencies
``` 
npm install
```
3. Start the development server

```
npm run dev
```
This launches the app at 
http://localhost:5173

.

3. Build for production

```
npm run build
```

This creates an optimized bundle in the dist/ folder.

4. Preview the production build

```
npm run preview

```
5. Type checking

```
npm run typecheck

```
6. Linting
```
npm run lint
```
No backend setup or environment configuration is needed — the HL7 Inspector runs entirely in the browser, so no data is sent to any server.
